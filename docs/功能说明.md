# 功能说明

> 一个浏览器标签页管理扩展的功能说明（面向功能与使用，不含实现细节）。

---

## 一、产品简介

一键把「打开过多的标签页」折叠成一张可管理的列表，释放内存、减少杂乱；需要时再逐个或整体还原。

- 免费使用，无需注册账号
- 数据默认保存在本机
- 关闭页面、重启浏览器或断电重开，列表都不会丢失

---

## 二、核心概念

| 概念 | 说明 |
|---|---|
| 标签条目 | 一条被保存的网页链接（含标题与图标） |
| 标签组 | 一次「收起」产生的若干标签，是列表里的基本卡片单位 |
| 文件夹 | 可容纳多个标签组，形成「文件夹 → 组 → 标签」两级结构 |
| 快捷列表 | 独立的一栏，放置最常用的条目，随时取用 |
| 星标 | 把某个组置顶显示 |
| 锁定 | 保护某个组不被误删；从锁定组还原的标签仍留在列表中 |
| 任务 | 给条目加待办标记，完成后可再点一次标记完成 |
| 备注 | 给条目或组添加文字说明，方便日后回忆用途 |

---

## 三、功能清单

### 1. 收集标签
- **一键收起**：点击扩展图标，把当前窗口的所有标签收起为一个列表并关闭它们。
- **按范围收集**：在网页中右键，可选择只收集「当前标签 / 其他标签 / 左侧标签 / 右侧标签 / 全部标签」。
- **只收选中项**：先在标签栏多选（按住 Ctrl / ⌘ / Shift），再只把选中的标签收起。
- **快捷键收集**：提供键盘快捷键，一键完成收起。
- **收集策略**：可设置是否连同「固定标签」一起收起、是否允许重复标签。

### 2. 恢复标签
- **单条恢复**：点击某条标签，在新标签页中打开。
- **整组恢复**：一键打开某个组内的全部标签。
- **全部恢复**：一键恢复列表中所有标签。
- **恢复方式可设置**：还原到当前窗口或新窗口；还原后是否从列表中移除。

### 3. 组织与整理
- **拖拽排序**：拖动组卡片调整组的顺序，落点由一条蓝色插入线指示；组内条目也可拖动排序。
- **排序区 / 合并区**：卡片的上、下两段（各约 30%）是排序区，出插入线；只有**中间约 40%** 才是「合并到此组」，避免想排序时误触合并。
- **拖出建组**：把条目拖到列表空白处，即可创建一个新组。
- **拖入合并**：把组拖到另一个组的中间区域，两组合并（锁定组不收外来内容）。
- **随时可取消**：按 Esc 或把卡片拖出列表，插入线与高亮立即消失，顺序不变。
- **星标置顶时**：置顶组固定在顶部，拖拽不会跨过这条分界线（插入线本身就停在该边界上，看到即所得）。
- **文件夹管理**：把组归入文件夹，分门别类。
- **重命名**：为标签组命名，便于识别。
- **星标置顶**：把常用组置顶显示，多个置顶按标记顺序排列。
- **锁定**：保护重要组不被误删。
- **多选与批量操作**：勾选多个条目后统一删除、恢复或移动。
- **删除与清空**：支持删除单条、删除整组、清空列表。

### 4. 搜索
- **页面内搜索**：在列表页直接输入关键词即时筛选已保存的标签。
- **地址栏搜索**：不必打开列表页，直接在浏览器地址栏输入关键词即可检索已保存的标签。

### 5. 标记（星标 / 任务 / 备注）
- **星标**：标记重要条目。
- **任务**：给条目加待办，完成后标记为已完成。
- **备注**：记录「当初为什么留着这些标签」。

### 6. 快捷列表
- 把常用条目拖入独立的「快捷列表」栏，随时快速访问。

### 7. 导出 / 导入 / 分享
- **导出**：把标签列表导出为链接清单，用于备份或迁移。
- **导入**：把链接清单导入回来。
- **分享为网页**：把某个标签组生成一个可分享的网页链接（含二维码），发给他人或在其他设备打开。**这是唯一会把数据对外分享的功能，需用户主动点击。**
- **复制链接**：把组内链接复制到剪贴板。

### 8. 资料库与同步
- **资料库就是一个普通文件夹**：你的标签组以一个个可读的小文件存放其中，用任何文本编辑器都能打开，也能直接手写一份放进去。
- 把资料库放在 OneDrive 等云盘里，即可由云盘自动同步到其他设备；不依赖任何服务器与账号。
- 每次变更都会自动写入文件，**无需手动保存**；在文件管理器里改名、移动、删除文件，回到扩展重新扫描即可识别。
- 删除的组会被移到资料库里的回收站，不会直接抹掉。
- **不需要「导出/备份」作为必需步骤**：文件夹本身就是你的数据，云盘的历史版本就是备份。（仍保留导出/导入，用于把清单交给别人。）

### 9. 设置
- 启动时是否自动打开列表页
- 固定标签是否一并收起
- 重复标签如何处理
- 还原到哪个窗口、还原后是否从列表移除、是否清空列表
- 是否启用点击图标弹出的快捷弹窗
- 资料库文件夹的位置，以及「立即写入 / 重新扫描」
- 快捷键查看与修改

### 10. 界面与主题
- 提供深色模式。
- 支持多种语言。
- 列表页支持拖拽、多选、搜索等操作，简洁直观。

## 四、典型使用流程

1. **打开太多标签，浏览器变卡** → 点击扩展图标，一键收成列表，内存立刻释放。
2. **想继续之前的调研** → 在列表里点开需要的标签，或整组一次性打开。
3. **长期累积了很多组** → 用文件夹分类、用星标置顶常用项、用搜索快速定位。
4. **担心换电脑或重装丢数据** → 把列表备份到 OneDrive，在新设备上恢复即可。

---

## 五、使用中的边界说明

- 收起后原标签会被关闭；**恢复时重新打开网页，但不会保留当时的页面状态**（如滚动位置、已填表单、页面内的临时操作），这是浏览器本身的限制。
- **尚未连接资料库时**，数据只暂存在本机；连接资料库后会自动写入你选定的文件夹。
- 只有一个组以上同步设备同时改动同一份文件时，云盘可能生成「冲突副本」，需要你手动确认保留哪一份。
- 部分浏览器（如 Safari）功能略有差异，个别高级功能可能不可用。
